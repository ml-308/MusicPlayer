# 轻音播放器 Light Music Player

一个免安装、双击即用的本地音乐播放器。用 C# 编译成单个原生 exe，除了 Windows 自带的
.NET Framework 以外不依赖任何运行库，不联网、不写注册表；设置与缓存都放在程序自己所在的
文件夹里，整包拷走即用（绿色便携）。

## 一、启动时弹出「Windows 已保护你的电脑 / 无法识别的应用」怎么办

这**不是病毒报警**，是 Windows 对「未签名程序」的信誉拦截（SmartScreen / 应用和文件检查）。

### 最省事的办法（立刻见效，不改任何设置）

双击 **启动播放器.bat** 来打开程序，或者给它建一个桌面快捷方式，以后双击快捷方式。

原理：这个弹窗只在「资源管理器（外壳）启动程序」时出现；批处理是通过命令行创建进程，
不经过外壳检查，所以不会弹。程序本身、功能、曲库、设置完全一样。

### 彻底的办法（以后双击 exe 也不再弹）

取决于拦截来源，二选一：

* 文件带「来自 Internet」标记（下载标记 MOTW）——从浏览器 / 网盘 / 聊天软件保存的文件都会有。
* Windows 11 的「检查应用和文件」开关，会按信誉拦截未签名程序。

双击 **彻底去弹窗.bat**，它会先显示当前状态（哪个文件有下载标记、开关是开还是关），然后可以：

    1  只清除下载标记（不改任何系统安全设置）
    2  清除下载标记 + 关闭「检查应用和文件」（彻底不再弹蓝窗）
    3  恢复 Windows 默认安全设置（撤销选项 2）
    4  打开「应用和浏览器控制」设置页（自己动手关掉那个开关）
    5  用 启动播放器.bat 的方式启动
    0  退出

若选项 2 提示「系统拒绝自动修改」（被篡改防护保护），用选项 4 或手动四步：

1. 开始菜单搜索并打开 **Windows 安全中心**
2. 左侧点 **应用和浏览器控制**
3. 点 **基于声誉的保护**
4. 把 **检查应用和文件** 关掉（立即生效，不用重启；Defender 的病毒防护仍然开着）

关掉后随时可以按同样路径重新打开，或用工具的选项 3 恢复默认。

### 其他说明

* 手动解除单个文件：右键 MusicPlayer.exe → 属性 → 常规 → 勾选最下方的「解除锁定」→ 确定。
* 临时放行：点弹窗里的「更多信息」→「仍要运行」（下一次还会弹）。
* 本程序不联网、不写注册表、对音乐文件只读（共享只读方式打开），可以放心运行。
* 想让 Windows 完全信任，正规做法是购买代码签名证书（EV 证书才有即时信誉）；
  自编译小工具通常会长期被视作「未知发布者」，所以上面的办法是最实用的处理方式。

### 安装版（MusicPlayerSetup.exe）

双击 dist 目录里的 MusicPlayerSetup.exe（或者从 GitHub Releases 下载），安装向导会：

1. 让你选择安装位置；默认是 %LOCALAPPDATA%\Programs\LightMusicPlayer，**不需要管理员权限**
2. 可选：创建桌面快捷方式、开始菜单快捷方式、安装完成后启动播放器
3. 安装完成后会在 Windows 的「已安装的应用」里登记，可以随时卸载

安装包里已经带了便携版的全部文件（主程序 + 源码 + 文档 + 启动/去弹窗脚本）。卸载会删除
程序文件与快捷方式，不会影响你的音乐文件。

命令行参数（脚本化安装）：

    MusicPlayerSetup.exe /silent                静默安装到默认位置
    MusicPlayerSetup.exe /silent /dir=D:\App    静默安装到指定目录
    MusicPlayerSetup.exe /silent /nodesktop /nostartmenu  不创建快捷方式
    "<安装目录>\Uninstall.exe" /uninstall /silent        静默卸载

## 三、桌面歌词

播放时会在屏幕下方浮出一条歌词栏，跟随播放逐字高亮（卡拉 OK 效果），参考 Ever Play 的歌词视觉：

* 当前句：大号加粗，已唱部分由灰变白、从左往右推进
* 翻译行：如果 .lrc 里同一时间点有两行（原文 + 翻译），第二行会以小字显示在下方
* 下一句：在最下方以暗色预告，方便跟着唱
* 换句时有一小段上滑淡入，播放暂停时高亮会停在原处

怎么用：

* 打开 / 关闭：底部工具栏的「歌词」按钮、右键托盘图标、或快捷键 Ctrl + L
* 移动位置：直接拖动歌词窗口，位置会记住
* 锁定（鼠标穿透）：双击歌词窗口 → 锁定后鼠标可穿过歌词栏点下面的东西；再双击解锁
  （锁定时无法用鼠标点它，用 Ctrl + L 或托盘菜单关闭）
* 右键歌词窗口：锁定 / 解锁、字号增大 / 减小、隐藏歌词、打开设置
* 设置 → 桌面歌词：启用开关、歌词字号（14-64）、背景不透明度（25-100）、锁定、复位位置

歌词从哪里来：

1. 与歌曲同名的 .lrc 文件（推荐），例如：
       歌曲.flac
       歌曲.lrc
   支持 UTF-8 / UTF-8 BOM / UTF-16 / GBK 编码；支持 [ti:] [ar:] [offset:] 等标签、
   一行多时间戳、以及逐字标签（会被忽略，按整行推进）。
   如果同目录找不到同名文件，还会尝试「标题.lrc」和「艺术家 - 标题.lrc」。
2. 音频文件内嵌歌词：MP3 的 USLT、FLAC / OGG 的 LYRICS 标签、M4A 的 ©lyr。
3. 都没有时，歌词栏会显示「暂无歌词 · 把同名 .lrc 文件放在歌曲旁边即可显示」。

## 四、为什么"不会一次性把音乐全部读进来"

* 扫描时只读取每个音乐文件的标签区（ID3 / Vorbis / MP4 / FLAC 元数据块等，通常只有几 KB），
  读完一个文件立刻关闭，绝不把整首音频载入内存。
* 列表是虚拟列表：几万首歌曲也只绘制屏幕上看得见的那几行。
* 播放时按需打开当前这一首，播完即释放；不会预加载下一首，也不会把整个文件夹的音频拷到别处。
* 歌词也是切歌时才去读对应的 .lrc（几 KB），读完即缓存，不参与扫描。

## 五、主要功能

曲库

* 添加整个文件夹（可递归包含子文件夹、可排除指定目录）、添加单个文件、也可把文件夹或文件直接拖进窗口
* 支持格式：MP3、WAV、WMA、FLAC、M4A、AAC、OGG、Opus、AIFF、APE、WV、MP4、MKA
* 读取标题 / 艺术家 / 专辑 / 专辑艺术家 / 流派 / 年份 / 音轨号 / 时长 / 比特率 / 采样率 / 大小
* 封面显示：只在播放当前歌曲时按需读取，不影响扫描速度
* 搜索过滤、点表头排序、随机打乱、移除 / 清空、复制路径、在资源管理器中定位、查看歌曲属性
* 播放列表 m3u 导入 / 导出
* 扫描过程实时显示进度，可随时停止；支持一次加入几万首

播放

* 连续播放（列表循环）、顺序播放、单曲循环、随机播放
* 随机模式会避免短时间内重复播放，并且"上一首"可以回退
* 播放 / 暂停 / 停止 / 上一首 / 下一首，进度条任意拖动定位，音量调节与静音
* 播放模式一键切换，状态栏实时显示当前音频引擎与播放模式
* 桌面歌词（逐字高亮 / 翻译 / 下一句预告，可拖动、可锁定穿透）
* 定时停止：设置里填分钟数，到点自动停止
* 关闭窗口可最小化到系统托盘，托盘右键菜单可直接控制播放

设置（工具栏的"设置"按钮）

* 常规：主题（深色 / 浅色）、启动自动扫描、记住播放列表与进度、显示封面、关闭时最小化到托盘、使用缓存
* 播放：默认播放模式、默认音量、快进 / 快退秒数、随机不重复深度、当前歌曲播完即停、定时停止
* 目录：音乐文件夹增删、递归开关、排除目录、可识别的扩展名
* 桌面歌词：启用、字号、不透明度、锁定、复位位置
* 音频引擎：引擎选择、一键检测本机可用引擎、清除扫描缓存
* 关于：版本信息与全部快捷键

## 七、音频引擎说明

程序内置两个播放通道，自动选择、失败自动回退：

1. Windows 媒体引擎（Media Foundation，推荐）
   支持 MP3 / WMA / WAV / FLAC / M4A(AAC) / ALAC 等，与系统播放器同一套解码器。
2. MCI 音频接口（兼容模式）
   系统自带的老接口，作为后备，通常用于 WAV。

* 默认"自动选择"：优先使用 Windows 媒体引擎，遇到打不开的文件自动退回 MCI。
* 某首歌播放异常时，可在 设置 - 音频引擎 中手动指定引擎；同一页面的"检测本机可用引擎"
  按钮会立刻报告这台电脑上哪个通道可用。
* 状态栏中间的"引擎：xxx"始终显示当前实际使用的通道。
* 若某个文件两种引擎都打不开，程序会在状态栏给出提示并跳过，不会卡死。

## 八、重新编译（可选）

源代码是纯 C#，不需要 Visual Studio、不需要联网：

* 双击 src\build.bat，或在该目录执行 csc @build.rsp
* 编译产物会输出到上一级目录并覆盖 MusicPlayer.exe

编译只使用 Windows 自带的 .NET Framework 编译器（csc.exe）以及系统自带的

## 九、常见问题

问：会不会把我的音乐文件改坏？
答：不会。程序对音乐文件只读（以共享只读方式打开），从不写入、重命名或删除你的音乐。

问：为什么有些歌曲显示"未知艺术家"？
答：该文件本身没有填写标签。列表会自动退回到用文件名显示，不影响播放。

问：扫描很慢？
答：第一次扫描需要逐个读取每个文件的标签；之后开启"使用扫描缓存"后，同样的文件直接读缓存，
速度提升明显。也可以在设置里临时移除不常听的大目录。

问：歌词不显示 / 对不上？
答：确认 .lrc 与歌曲同名且在同一目录；歌词与音乐的时间轴由 .lrc 里的时间戳决定，
如果整体偏移，可以在 .lrc 里加一行 [offset:毫秒] 来整体提前或延后。

问：换电脑后设置还在吗？
答：在。MusicPlayer.config.json 就在程序目录里，跟着整个文件夹一起走即可。

## 十一、发布到 GitHub（维护者用）

仓库已经初始化（分支 main，标签 v1.0.0），并附带一键发布脚本。

双击 发布到GitHub.bat，按提示输入：

1. GitHub 用户名
2. 仓库名（直接回车使用默认的 light-music-player）
3. 仓库是否私有
4. Personal Access Token（在 https://github.com/settings/tokens 生成，勾选 repo 权限即可）

脚本会自动完成整条链路：创建仓库 → 提交并推送 main → 推送标签 v1.0.0 → 创建 Release
→ 上传 dist 目录里的 MusicPlayer-1.0.0-portable.zip 和 MusicPlayerSetup.exe，最后打印仓库与 Release 地址。

说明：

* 浏览器里保存的密码无法（也不应该）被脚本读取，因此用 Token 方式，Token 只在本次运行内存里使用，
  不会写进 .git/config。
* 仓库只提交源码与文档；生成出来的 MusicPlayer.exe、安装包和 dist/ 都在 .gitignore 里，
  统一通过 Release 分发。用户数据（config/cache/error.log）同样不提交。
* 也可以手动完成：

      git remote add origin https://github.com/<用户名>/<仓库>.git
      git push -u origin main
      git push origin v1.0.0

  然后到网页上 New release，选择标签 v1.0.0，把 dist 里的 zip 拖上去即可。
